# StoneVeld Website — Current Design Direction

The StoneVeld website is still actively being built, tested, and shaped.

We are currently experimenting with how the site should work and feel — not only how it looks. Some ideas will stay, some will change, and some will be removed as we learn what actually works.

## Current design ideas

- A clear corporate front door that explains StoneVeld.
- A more visual and interactive area further down the main page.
- Separate spaces for Leon's Studio and Bianca's Studio.
- A combined Workspace + Lab area showing the real development and research environment.
- Real project material, such as RAG Trigger Studio, rather than purely decorative portfolio content.
- A future browser-based StoneTerminal where visitors can experiment and interact with software ideas.

This is an active design process. We are building one piece at a time, testing each change, and deciding what deserves to stay.

**StoneVeld is still under construction — and that's part of the project.**
