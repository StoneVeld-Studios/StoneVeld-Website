Contingency Recovery

Contingency Recovery is StoneVeld Studios’ private, operator-managed Google Drive connection for storing recoverable copies of the Contingency Federation system.

Status: setup in progress.

This connection is intended for the StoneVeld operator's own Google account. It is not a public backup service, a public sign-in portal, or a feature offered to Contingency users.

What it does

We use the open-source rclone utility to connect an authorised Google account to Google Drive. The planned backup workflow places encrypted backup archives in private Drive storage, then tests the ability to retrieve and recover them.

Backup archives can contain Contingency's PostgreSQL database, private uploads and Git repository data. Google Drive is the storage destination. Backup encryption is configured locally before any production archive is uploaded. Setup and upload verification are not yet complete.

Who can use it?

Only a Google account explicitly authorised by the StoneVeld operator. The utility does not invite users to register or grant general access to their Google Drive.

Google Drive access

The connection requests permission during Google's consent flow. Our intended configuration is the narrower drive.file permission, which allows rclone to manage files created or opened through its connection. The exact scope shown at authorization must be reviewed before use.

You can revoke a Google account's permission at any time using Google Account connections. Revocation prevents future access using that authorisation, but does not necessarily delete files already stored in Drive.
